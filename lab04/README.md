# Решения
- Книги равны, если совпадает ISBN. Название в равенстве не участвует.
- SampleId равен другому SampleId, если совпадают datasetName и number.
- equals и hashCode используют одни и те же поля.
- Ключевые классы final и неизменяемы, чтобы hashCode не менялся после put в HashMap.
- SampleRegistry.get возвращает null, если образца с таким ключом нет.
- Повторный put с равным ключом заменяет значение, размер реестра не растёт.

# Эксперименты
- Коллизия: ключи с одинаковым hashCode остаются разными, потому что HashMap сравнивает их через equals.
- Изменяемый ключ: если изменить поле, от которого зависит hashCode, после put запись остаётся в старой корзине и становится недостижимой по ключу.
